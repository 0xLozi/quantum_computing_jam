# ⚛️ Quantum Computing Jam
¡Bienvenido/a al repositorio **quantum_computing_jam**! 🚀

Este espacio está dedicado solamente al aprendizaje práctico e interactivo de los fundamentos de la **Información y Computación Cuántica**, utilizando **Python** y **Qiskit**. Contiene la resolución paso a paso de ejercicios prácticos, junto con notas teóricas organizadas para consulta rápida.


### Tecnologías y Librerías Utilizadas
- Lenguaje: Python 3.10+
- Framework Cuántico: Qiskit (qiskit.quantum_info, Statevector, Operator)
- Cálculo Numérico: NumPy (np.outer, np.trace, np.conj)
- Gestión de Conocimiento: Obsidian (para el vault de notas vinculadas)
